# Embassy Appointment USSD System

A USSD-based system for managing embassy appointment bookings and scheduling.

## Description

This USSD application allows users to schedule and manage their embassy appointments through their mobile phones using USSD codes. The system provides a simple and accessible way for users to:

1. Schedule Appointment
   - Tourist Visa
   - student visa
   - work visa
2. View/Cancel Appointment
3. Reschedule Appointment
4. Contact Embassy
5. Exit

## Features

- Easy-to-use USSD interface
- Secure user authentication
- Real-time appointment scheduling
- Appointment status checking
- SMS notifications for appointments
